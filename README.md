# 家乡麻将（联机版）

可以和同学联机的家乡麻将：胡头 × 台数计分、8 张花牌、吃碰杠胡、见逃、抢杠、连庄。

## 项目结构

```
app/      前端：React + TypeScript + Vite + Tailwind（大厅 / 牌桌 / 结算）
server/   联机服务器：Node.js + WebSocket（房间制 + 回合引擎）
shared/   前后端共享的纯 TS 规则引擎（牌、胡头/台数计分、结算、流局判定）
```

## 本地运行

需要 Node.js 20+。

```bash
# 终端 1：游戏服务器（ws://localhost:8080）
cd server
npm install
npm run dev

# 终端 2：前端（http://localhost:3000）
cd app
npm install
npm run dev
```

打开 http://localhost:3000 ，创建房间后把 6 位房间码发给同学即可联机（同一局域网直接访问你的 IP；公网需自行部署服务器并修改 `app/src/lib/ws.ts` 里的 `WS_URL`）。

## 游戏规则（胡头 × 台数）

- 136 张牌 + 8 张花牌（春夏秋冬梅兰竹菊），摸花放一边、从牌墙末尾补牌
- 特殊牌 = 幺九与字牌。普通碰 2 / 暗刻 4 / 杠 8 / 暗杠 16 胡，特殊翻倍
- 胡牌 30 底；自摸 +2；坎张、边张 +2；将对为三元或自风牌 +2
- 花牌每张 4 胡；自己的花每台 1；集齐春夏秋冬或梅兰竹菊额外 1 台
- 台数：自风/三元碰杠各 1 台（暗刻也算）、清一色/字一色 3 台、混一色 2 台、对对胡 2 台，累加上限 3 台
- 最终胡头 = 基础胡头 × 2^台数，向上取整到 10，封顶 300
- 结算：点炮者付胡牌者胡头/10，其他两家付一半（向上取整）；自摸三家各付胡头/10；非胡牌者之间按胡头差结算（庄闲 /10、闲闲 /20 向上取整）
- 流局：牌墙剩 18 张（每杠 +2）时流局，庄位顺延；胡牌者坐庄（连庄）
- 可以吃上家；支持见逃（过胡后本轮不能再胡）与抢杠（不可抢暗杠）

## 测试

```bash
cd server
node test-rules.ts    # 规则计分 60 项断言
node test-engine.ts   # 回合引擎确定性测试（注入牌序）
node test-smoke.ts    # 联机冒烟（建房/加入/开局）
node test-play.ts     # 4 个机器人自动对局
```

`牌型核验.md` 里有 15 组程序生成的牌型算例，供人工核验计分规则。
